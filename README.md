# Swordfish FM

> **⚠️ Work in Progress - Not ready for release yet**

Swordfish FM is a lightweight, fast file manager for X11 - forked from Xfe 2.1.11 and currently being rebranded and refactored.

This project is under active development. APIs, binaries, and UI may change. Do not use in production yet.

### Status
- [x] Rebrand xfe -> swordfish, xfa -> swfa, xfi -> swfi, xfp -> swfp, xfw -> swfw
- [x] Help text and usage strings fixed
- [x] Build system cleaned (config.h not tracked)
- [ ] New README, logo & icons
- [ ] Theme and UI polish
- [ ] First tagged release (v1.0.0)

### What is it?
Fast C++ / FOX Toolkit file manager, low memory footprint, dual-pane commander mode, tree view, tabs, and built-in tools.

Features inherited from Xfe:
- 4 view modes: one panel, tree + one panel, two panels, tree + two panels
- Horizontal / vertical stacking, dockable toolbars, tabs, Places bookmarks
- Built-in editor (swfw), image viewer (swfi), archiver (swfa), package viewer (swfp)
